# 物料与板本核对

本记录使用 **V1.2.1** 主板。原作者的 [V1.2.1 物料清单 PDF 与焊接图](https://oshwhub.com/sngelswyh/stm32-smart-desktop-pet) 是数量、封装、方向与排针位置的最终依据；下表提炼本次路线中需要识别的主要部件，不替代 PCB 丝印。

| 部件 | 数量/规格 | 用途 |
| --- | --- | --- |
| V1.2.1 PCB 与外壳 | 各 1 套 | 必须与固件和装配孔位匹配 |
| SG90 舵机 | 5 个，180° | 四条腿和尾巴 |
| STM32F103C8T6 最小系统板 | 1 块，带排针 | 主控；本次识别为 `0x0410` |
| OLED | 1 块，1.3 英寸、4 针 I²C | 表情和状态 |
| SU-03T1 | 1 块，带排针 | 离线语音；另配咪头、喇叭 |
| 蓝牙模块 | 1 块，4 针、SPP | 远程动作控制；波特率取决于具体模块/原固件 |
| CH340 USB 转 TTL 串口模块 | 1 个 | STM32 与语音模块的电脑串口连接 |
| 5V 充放电模块、3.7V 聚合物锂电池 | 各 1；电池 ≥1000mAh、2.0mm 红黑端子 | 整机供电 |
| 其余小件 | 0805 电阻/电容/LED、680µF/10V 电容、33µH 电感、SMF6.0A、排针排母、开关和 OLED 连接线 | 按原 PDF 与 PCB 核对具体数量及方向 |

原作者在项目页提到原 V1.2.1 供电设计可能无法覆盖四路舵机同时动作的峰值负载；如果整机动作时复位，应先测 5V 轨和电源能力，不要把所有复位都归因于 Mac 烧录。[原项目说明](https://oshwhub.com/sngelswyh/stm32-smart-desktop-pet)

采购 CH340 时，**“VCC 可选 3.3V/5V”不等于 TX/RX 信号必定为 3.3V**。SU-03T1 模块本体 5V 供电，但 UART 引脚规格为 3.3V；烧录前确认转换器的逻辑电平。[SU-03T 规格](https://docs.aimachip.com/zh-cn/latest/file/offlineVoice/SU03T.html)
