# 装配与验收

本页列出 V1.2.1 的验收顺序；机械孔位、极性、焊接朝向和舵机臂安装角度以[原作者的 V1.2.1 焊接图、模型与视频](https://oshwhub.com/sngelswyh/stm32-smart-desktop-pet)为准。当前用户设备尚未装回完成整机测试，以下是待执行的验收步骤。

1. 断电后确认 STM32 **BOOT0=0**；分别完成 MCU 与独立语音模块烧录，保存各自成功记录。
2. 按 PCB 丝印检查电源模块、电池红黑线、LED/TVS/电解电容极性，再接电源。先确认 5V 和 3.3V 轨稳定，再插敏感模块。
3. 插 STM32、OLED 和蓝牙模块。V1.2.1 的蓝牙模块尺寸/插座与旧版不同；长条模块与小模块的通信波特率可能不同，应按原作者相应固件说明设置。
4. 四腿加尾巴共五个 SG90。安装舵机臂之前按原作者教程调中位，核对舵机供电、GND、PWM 方向，避免上电时机械卡死。
5. 独立升级成功的 SU-03T1 再插回语音座；主板通信使用该版固件配置的 B0/B1，烧录用的 B6/B7 不要误当主板控制线。咪头、喇叭按原图连接。
6. 先空载上电观察 OLED、蓝牙与模块开机；再逐个测试四腿、尾巴、灯光、电量显示和语音。原项目指令表中唤醒词为“你好小智”，动作码包含 `0x31` 站立、`0x33` 前进、`0x40` 摇尾巴；语音和蓝牙分别测试，再测试联动。

如果舵机一动就复位，检查电源输出与瞬时电流。原作者在项目后期说明 V1.2.1 的充放电模块可能不足以支撑四腿同时动作；这类情况不能靠重复刷固件解决。[原项目说明](https://oshwhub.com/sngelswyh/stm32-smart-desktop-pet)
